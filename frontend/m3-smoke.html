M3 Frontend Smoke Tests

Runs real frontend modules with deterministic Web Speech API stubs. Backend-integrated checks are listed below for manual verification.

    Manual verification

    1. Submit an ambiguous query in the main app and verify the clarification response appears.
    2. Answer the clarification and verify the same session resumes through retrieval and response generation.
    3. Create two conversations, switch between them, and verify messages do not leak across sessions.
    4. Start a new conversation and verify the previous conversation is no longer active.
