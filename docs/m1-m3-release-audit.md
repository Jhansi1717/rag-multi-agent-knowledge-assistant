## Pre-Fix Evidence

- Python: **393 passed, 0 failed, 0 skipped**, one Starlette deprecation warning. Run from a disposable copy with an isolated embedding/index cache.
- Browser harness: **16 passed, 0 failed**. Web Speech APIs are deterministic mocks; the harness does not provide a rendered TTS stop control.
- M1 retrieval: regenerated 8-document, 2-domain corpus in the disposable copy; 15 available queries scored 100% Hit@1/3/5. The 27-row dataset also contains 8 ambiguous and 4 unavailable cases; the evaluator currently reports those as retrieval failures rather than separate outcomes.
- M2 end-to-end evaluator: 20 cases, 100% classification and expected-evidence retrieval for available cases, 75% no-evidence handling, 85% script success. It reuses one session for unrelated cases and uses a mock provider, so these are not real-generation acceptance results.
- Live browser: uploaded TXT, PDF, DOCX and CSV, listed original names, exercised corrupt-file failure/recovery, chat/clarification/session flow, mocked STT transcript editing/permission error, TTS play/pause/resume/switch, keyboard Knowledge Base toggle, and 390/1440px widths.
- Real-provider validation: blocked because `OPENAI_API_KEY` is not configured.

No source code has been changed during this first audit pass. Milestone 4 has not been started.
