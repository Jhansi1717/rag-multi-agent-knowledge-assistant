## Baseline test record

- Full pytest in the source tree with the default model cache: 7 collection errors from Hugging Face cache/model initialization.
- The public embedding model loaded successfully after redirecting `HF_HOME` to a temporary directory.
- Full pytest then ran in the source tree due a sandbox path mismatch: 380 passed, 5 failed. The five failures are in `test_m14_retrieval.py`; the evaluation index currently contains one unrelated upload chunk, not the expected eight-corpus documents.
- Independently collectible M1/M2/M3 suites passed earlier (245 tests). This is not a substitute for the full suite.
- The destructive `test_retrieval.py` changed ignored project data. Index and metadata were restored from the intact workspace-level mirror and checksummed; the mirror uses a different UUID. Only the generated test upload was removed.
- No source code has been changed during this initial audit pass. Existing user modifications are preserved.
